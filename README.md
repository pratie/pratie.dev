# pratie.dev

Personal site and notes on how language models work.

- `src/content/notes/` holds the notes (MDX).
- `src/components/figures/` holds the interactive figures.
- `scripts/gpt2_figures.py` writes the real GPT-2 numbers the figures use.
- `scripts/gpt_numpy.py` is a GPT forward pass in NumPy, checked against GPT-2.

```sh
npm install
npm run dev
```

See `CLAUDE.md` for how to add a note.
